# Documentation images

Add plugin screenshots here so they render on the README and on the
[plugin documentation page](https://plugins.jenkins.io/failure-provenance/).

Files referenced from the top-level `README.md`:

- `build-page.png` — the build page summary line for a recurring failure
  ("this failure has been seen before"), with the **Details** link.
- `build-page-details.png` — the full **Failure Provenance** report: matching
  builds with similarity percentages, the signature, and the normalized
  evidence.

Guidance:

- Capture at a normal browser width; crop to the panel content.
- Prefer light-theme Jenkins for readability on the plugin site.
- Keep file size reasonable (optimize PNGs before committing).
